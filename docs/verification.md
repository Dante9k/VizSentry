## 已验证

- Python 自动测试：数据库、API、任务引擎、Excel、图片/日志/模型、飞书适配器的模拟接口。包括空表、跨页、重复 ID 拒绝、分页完整性、中文字段、令牌续期、附件权限上下文、跨域认证隔离、连接器批次/令牌/持久化与快照范围校验。
- 图片检测：损坏图、小图、纯色、模糊、照片/截图型样例，BRISQUE 权重完整性、无网络运行和重复计算稳定性。
- 模型模拟：超时、限流、错误 JSON、逐图结果、分块日志和缓存内容/设置隔离。实际视觉模型效果未验收。
- 引擎：取消和启动的竞态、暂停继续、进程中断恢复、失败重试、不完整导入拒绝分析、缓存文件缺失/损坏恢复。
- Excel：主表 N 行、图与记录对应、公式样文本按文本保存、隐藏详情表、超过单元格限制的中文长日志与换行重组、空表。
- 浏览器：Node 读取器单元测试；真实 Chromium 连接本机模拟站点，验证并发 RPC、原始日志、HTML 片段、分页结束、缺少下一页、登录提示、Cookie 图片下载以及跨域移除令牌。
- 网页构建：React/TypeScript 和飞书 SDK 连接器构建通过。
- 网页交互：本地 6 行演示完整运行；多图、缺图、空日志和损坏图片均保留原行；筛选、日志展开、失败重试、设置和刷新后持久化正常，浏览器控制台无错误。
- Windows 启动：`start.ps1 -NoBrowser` 启动服务成功，健康检查和连接诊断正常，CPU 模型及校验后的权重可用。Windows DPAPI 在正常用户进程通过保存/读取测试。

## 规模测试

模拟数据以小批次写入 SQLite，不构造全量图片或日志。1 万行与 10 万行均验证计数、顺序分页、恢复状态和不重复。

一次本机记录：1 万行约 0.67 秒，10 万行约 6.10 秒；Python tracemalloc 的清单路径峰值约 0.75 MB。该数字仅覆盖模拟清单导入路径，不包含解释器、SQLite 原生内存、浏览器、图片下载、模型推理或导出图片内存。

最终 HTTP 接口检查中，“任务状态 + 最后一页 50 行”合计：1 万行 0.026 秒、10 万行 0.083 秒；单页响应分别约 8.2 KB / 8.4 KB。验证返回条数、顺序、中文内容及计数，页面分页不会一次返回全表。时间是本机观测值，不作为跨设备性能承诺。

离线 CPU 示例：1920×1080 图片预热后约 0.32 秒，4000×3000 约 0.79 秒，BRISQUE 使用最长边 1024 的评估副本；这些数据不是吞吐量保证。真实性能需按图片大小、日志长度、网络和模型限流测量。
